# Nevilete

Nevilete is a CFA study tracker for managing syllabus progress, study sessions, goals, and preparation analytics.

## Features

* CFA syllabus tracking
* Study session tracking
* Goals and roadmap
* Study streaks
* Progress analytics
* Topic-wise progress
* User accounts
* Social features

## Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: FastAPI
* Database: PostgreSQL
* Authentication: JWT

## Setup

```bash
git clone https://github.com/jia-nil/nevilete.git
cd nevilete
npm install
npm run dev
```

Create a `.env` file with the required environment variables before starting the backend.
