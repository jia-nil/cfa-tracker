JEE Tracker
A data-driven dashboard for JEE prep, focused on mapping chapter weightage against personal progress to optimize rank potential.

Features

Strategy Engine: Automates study plans based on chapter priority and remaining time.

JSON Question Bank: Structured data management for large-scale problem sets.

Progress Tracking: Real-time status mapping (Completed/In-Progress/Revision) across the syllabus.

Symbol Parsing: Integration for handling mathematical constants and expressions.
